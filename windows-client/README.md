# Windows 托盘客户端

使用方式：

1. 安装 AutoHotkey 1.1
2. 运行 `CloudClipboardSync.ahk`
3. 首次启动会自动弹出同步面板，填写配置后点击“保存配置”
4. 点击“启动同步”建立连接；后续如果保留自动恢复，下次启动客户端会按上次状态自动续连
5. 如果用 `Ahk2Exe` 打包，脚本头已经指定 `assets/cloud-clipboard-sync.ico`，生成的 exe 不会再是默认 `H` 图标

也可以直接编辑 `config.ini` 作为高级配置入口。

配置项：

- `serverBase`：服务端地址，例如 `http://127.0.0.1:9501`
- `room`：房间名，可留空表示默认房间
- `roomPassword`：房间访问密码；如果该房间走全局密码，也在这里填写全局密码
- `deviceName`：当前 Windows 设备显示名；首次会默认取本机名称
- `deviceId`：设备唯一标识，首次生成后建议保持不变
- `runtimeDir`：运行态缓存目录；留空时默认跟随脚本目录，里面会放 `commands.log / events.log`
- `panelHotkey`：显示/隐藏同步面板的快捷键；面板里既可以手填 `Ctrl + Alt + V`，也可以点“录制快捷键”弹窗录入，留空则不注册热键
- `syncToggleHotkey`：一键启动/停止同步的快捷键；同样支持手填、录制或留空禁用
- `trayIconHotkey`：显示/隐藏托盘图标的快捷键；托盘已经隐藏时，也可以靠这个热键恢复
- `autoConnectEnabled`：是否允许按上次运行状态自动恢复同步，`1` 为开启
- `startupEnabled`：是否随 Windows 开机启动托盘客户端，`1` 为开启
- `lastDesiredRunningState`：最近一次用户期望的运行状态，`running` / `stopped`
- `hasConnectedOnce`：是否已经成功连接过至少一次，用于决定后续是否自动恢复

默认热键：

- `Ctrl + Alt + V`：显示/隐藏状态面板

面板能力：

- 直接修改服务端地址、房间、房间密码、设备名、设备 ID
- 主面板默认只保留高频配置和常用动作，避免整体高度过高
- “高级设置”里可以修改设备 ID、运行态缓存目录，以及三个快捷键
- 高级设置里也能开关“启动客户端后按上次状态自动恢复同步”和“跟随 Windows 开机启动本客户端”
- 托盘图标热键支持把托盘图标隐藏掉，也支持在隐藏后再次恢复
- 手动“启动同步 / 停止同步 / 重新连接”
- 手动“清理本地缓存”，用于清空 `commands.log / events.log` 这类运行痕迹；如果当前正在同步，会自动重连一次

说明：

- AHK 负责托盘、配置/状态面板、快捷键、文本剪贴板监听和运行状态持久化
- `sync-helper.ps1` 负责连接 Go 服务端同步协议
- `config.ini` 仍固定放在脚本目录；只有运行态缓存文件会跟随 `runtimeDir`
- 当前版本支持：
  - Windows 与 Web / Android 的纯文本自动同步
  - 从托盘或状态面板选择本地文件/图片，上传后通知 Android 端确认接收
  - 未批准时仅保活并提示等待网页端批准
  - 手动停止后，下次启动前不会自动恢复；再次点“启动同步”后才重新进入自动恢复链路
