# 自动同步使用与效果说明

本文档说明新增自动同步能力怎么使用，以及启用后应该看到什么效果。

## 一句话说明

自动同步适合“在一台设备复制文本，另一台设备自动收到并写入剪贴板”的场景。当前文本同步支持网页端、桌面端 Go 客户端和 Android 同步客户端三端；图片和文件的自动确认接收当前只在 Android 同步客户端实现。

## 前置条件

- 服务端已经启动，网页可以正常访问。
- 房间密码或全局密码已配置好；如果没有配置密码，则按当前服务端空密码房间语义接入。
- 新设备首次接入后，需要在网页端“设备 / 同步设备管理”中批准。
- 桌面端使用 [`desktop-client-go/`](../desktop-client-go)，Android 使用 [`android-sync-client/`](../android-sync-client)。

## 网页端怎么用

1. 打开服务端网页。
2. 进入需要同步的房间。
3. 打开“设备 / 同步设备管理”。
4. 填写或确认网页端设备名称。
5. 如果浏览器允许剪贴板权限，网页端会尝试自动读取本地文本剪贴板并上报。
6. 如果浏览器不允许读取或写入剪贴板，页面会退化为显示远端文本和一键复制。
7. 看到新设备进入 pending 后，点击批准，设备变为已连接后才会正式同步。

### 网页端效果

- 两个网页页面在同一房间内可以互相同步纯文本。
- 收到远端文本时，浏览器允许的话会自动写入系统剪贴板。
- 权限不足时不会阻塞使用，会显示文本并提供手动复制入口。
- 同步设备列表、状态摘要和诊断信息会自动刷新。

## 桌面端 Go 客户端怎么用

1. 进入 `desktop-client-go/`。
2. 运行桌面端客户端。
3. 首次运行会生成配置文件，并打开本地控制面板。
4. 在控制面板填写服务端地址、房间、房间密码和设备名称。
5. 保存并重连。
6. 回到网页端同步设备管理区批准该桌面设备。
7. 批准后，桌面端会开始监听本机文本剪贴板并同步远端文本。

### 桌面端效果

- 本机复制新文本后，会自动发送到同一房间的其它已批准同步设备。
- 收到远端文本后，会自动写入 Windows 系统剪贴板。
- 控制面板概览页会显示下一步建议、连接诊断、缓存目录、平台能力和最近缓存清理。
- 右下角 Tip、系统通知、日志或关闭通知可按需选择。
- 可配置全局热键、Windows 右键菜单、下载缓存目录和缓存保留时长。
- 自动重连达到配置上限后会暂停，并提示手动检查服务端或网络。

## Android 同步客户端怎么用

1. 安装 `android-sync-client`。
2. 打开 App，填写服务端地址、房间、房间密码和设备名称。
3. 点击保存并启动同步。
4. 回到网页端同步设备管理区批准 Android 设备。
5. 按页面提示补齐通知、悬浮窗、电池优化、无障碍或厂商后台保活等权限。
6. 在运行页查看后台复制就绪度、后台复制诊断和动态排查按钮。

### Android 文本同步效果

- 前台复制文本时，会同步到网页端和桌面端。
- 收到远端文本时，会尝试写入 Android 系统剪贴板。
- 在 Android 10+ 或部分国产 ROM 上，后台读取剪贴板可能被系统限制；运行页会提示当前模式风险和下一步处理入口。
- 无障碍增强模式、通知权限、电池优化和厂商后台保活状态会影响后台复制稳定性。

### Android 图片 / 文件接收效果

- 收到网页端或桌面端发来的图片 / 文件通知后，优先弹出悬浮确认。
- 未开启悬浮窗权限时，会退回系统通知。
- 用户确认后才会下载到 App 私有缓存。
- 下载后可在接收页预览图片、打开文件、分享、另存为或标记已处理。
- 默认缓存保留 24 小时，App 启动、回前台、同步服务启动和新下载前会触发清理。

## 当前边界

- 只做纯文本自动写入系统剪贴板，不做富文本自动同步。
- 不做第三方输入框自动粘贴。
- 图片和文件不会自动写入系统剪贴板。
- Windows / Web 当前不做图片和文件自动接收，只保留发送通知和手动下载能力。
- Android 图片 / 文件接收必须用户确认后才下载，不预下载。

## 快速验证

| 验证项 | 期望效果 |
|--------|----------|
| 网页复制文本 | 另一个网页或已批准客户端收到文本 |
| 桌面端复制文本 | 网页时间流和 Android 剪贴板收到文本 |
| Android 前台复制文本 | 网页时间流和桌面端剪贴板收到文本 |
| 新设备首次连接 | 网页设备管理中显示 pending |
| 网页批准设备 | 设备状态变为已连接，开始正式同步 |
| 网页或桌面端发送文件通知 | Android 弹出确认入口，确认后才下载 |
| Android 标记已处理 | 接收页状态更新，后续可清理已处理内容 |

## 常见问题

- Android 后台复制不回传：优先看运行页“后台复制就绪度”和“后台复制诊断”，再检查无障碍、通知、电池优化和厂商后台保活。
- 其它设备连不上：跨设备访问时不要填 `127.0.0.1`，应填写服务端所在机器的局域网 IP 或公网地址。
- 设备一直待批准：到网页端同步设备管理区批准对应设备。
- 收不到图片 / 文件确认：先确认 Android 悬浮窗权限；未开启时应至少能收到系统通知。
- 系统通知太多：桌面端建议使用 Tip 模式；Android 端建议开启悬浮窗确认。
