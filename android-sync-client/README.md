# Android Sync Client

该目录是“安卓同步客户端”，与仓库原有的 `android/` 服务器 APK 工程分离。

安卓客户端用于接入仓库中的新同步协议，当前阶段目标是：

* Android / Web / Windows 三端纯文本自动同步
* Android 接收图片 / 文件通知
* 用户确认后才下载到本地缓存
* 下载完成后在 App 内接收页处理，不自动写入系统剪贴板

## 构建

```bash
./gradlew assembleDebug
```

默认 Debug APK 输出位置：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 配置

首次打开 App 后填写：

* 服务端地址：例如 `http://192.168.1.10:9501`
* 房间：可留空
* 房间密码：如果房间设置了房间密码，就填房间密码；否则这里填写全局密码
* 设备名称：显示在网页端设备列表中

保存后点击“启动同步”。

## 当前行为

### 文本

* 本地文本剪贴板变化后会自动上报
* 收到远端文本后会自动写入安卓系统剪贴板
* 未通过房间密码时无法接入同步房间
* 未信任设备只保活连接，不发送文本

### 图片 / 文件

* 收到 `payloadNotice` 后会弹出系统通知
* 当前可由网页端上传完成后主动触发该通知
* 用户点击“确认接收”后才开始下载
* 下载目标是应用私有缓存目录，不会自动落到公共 Download 目录
* 下载完成后可在“接收页”中进行：
  * 图片预览
  * 打开文件
  * 分享文件
  * 另存为
  * 标记已处理

## 缓存策略

* 默认缓存保留 24 小时
* 清理触发时机：
  * App 启动
  * App 回到前台
  * 同步服务启动
  * 开始新的 payload 下载前
* “已处理”仅表示用户已经手动处理过，不会立刻删除缓存

## 限制

* 当前使用通知确认接收，尚未实现悬浮按钮确认
* 当前不做第三方输入框自动粘贴
* 当前不做图片自动写入系统剪贴板
* 当前非文本接收流程只在 Android 端实现
